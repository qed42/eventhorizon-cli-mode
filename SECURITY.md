# Security Policy

## About This Tool

EventHorizon CLI is a **static analysis** tool. It reads and analyzes source code files but **does not execute** any of the code it scans. It does not make network requests, access databases, or modify the target codebase.

## Reporting a Vulnerability

If you discover a security vulnerability in EventHorizon CLI itself, please report it responsibly:

1. **Do not** open a public GitHub issue
2. Email the maintainers at **<security@qed42.com>** with details
3. Include steps to reproduce, if possible

We will acknowledge your report at the quickest and aim to release a fix as soon as possible for critical issues.
